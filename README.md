# 🛠️ QA-Pipeline-Toolkit

Набор Python-скриптов и утилит для автоматизации рутины QA-инженера, обработки тестовых данных, генерации отчетности и ускорения повседневных задач при ручном тестировании.

## 📖 Описание проекта
Проект представляет собой пайплайн инструментов, закрывающий несколько болей QA-отдела:
1. **Очистка и миграция данных** (экспорт из TMS в читаемый вид).
2. **Генерация тестовой документации** (чек-листы, оглавления).
3. **Подготовка отчетов** (конвертация в форматы для стейкхолдеров).
4. **Повышение продуктивности** (десктопное приложение для быстрого ввода данных).

## 🧩 Модули и архитектура

### 1. Data Processing & Documentation (Пайплайн данных)
* **`json_cleaner.py`**: Рекурсивная очистка сырых JSON-данных (например, выгрузок из Jira/TestRail) от мусорных ключей, метаданных и пустых значений.
* **`md_generator.py`**: Парсинг очищенного JSON. Включает кастомный `HTMLToTextParser` для конвертации HTML-описаний шагов в чистый текст. Генерирует структурированный Markdown-чеклист для регрессионного тестирования и отдельный файл с оглавлением (TOC).

### 2. Reporting & Export (Отчетность)
* **`csv_exporter.py`**: Парсинг сгенерированного оглавления (`index.md`) и экспорт структуры тест-кейсов в CSV. Создает шаблон для трекинга статусов (Pass/Fail/Blocked), который можно импортировать в Excel или TMS.
* **`docx_converter.py`**: Конвертация Markdown-документации в формат `.docx` (с использованием `pypandoc`) для формирования официальных Test Summary Reports.

### 3. Daily Productivity Tool (Утилита для ручного тестирования)
* **`clipboard_hotkey_app.py`**: Десктопное GUI-приложение на `Tkinter`. Регистрирует глобальные хоткеи (`Alt+1`, `Alt+2`) для мгновенного копирования в буфер обмена заранее заданных тестовых данных (логинов, паролей, URL). 
  * *Техническая особенность*: Корректно реализована работа с глобальными хуками клавиатуры в отдельном потоке с безопасным взаимодействием с главным потоком Tkinter через `root.after()`.

## 🚀 Технологический стек
* **Язык:** Python 3
* **Работа с данными и парсинг:** `json`, `csv`, `re`, `html.parser` (кастомный парсер)
* **Генерация и конвертация документов:** `pypandoc` (Pandoc API)
* **GUI и системные интеграции:** `tkinter`, `keyboard`, `pyperclip`

## 💡 Как это использовать (Workflow)
1. Получить выгрузку тестов в JSON -> прогнать через `json_cleaner.py`.
2. Сгенерировать Markdown-чеклист и оглавление через `md_generator.py`.
3. *(Опционально)* Создать CSV-шаблон для сбора результатов тестирования через `csv_exporter.py`.
4. Подготовить финальный Word-отчет для руководства через `docx_converter.py`.
5. Запустить `clipboard_hotkey_app.py` для ускорения ручного прогона тестов.
